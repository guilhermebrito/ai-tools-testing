# Cursor

> [!NOTE]
> O Cursor evoluiu de uma IDE com autocompletar inteligente para uma **plataforma de agentes assíncronos** com Background Agents, BugBot, Automations multi-repo e integração com Jira.

## Visão Geral
O **Cursor** é a IDE AI-first mais popular do mercado, construída como um fork do VS Code. Ela herda todo o ecossistema de extensões da Microsoft, mas integra a IA profundamente em cada interação. Com a chegada da **versão 3.5** (maio 2026), a plataforma consolidou-se como um ambiente completo de orquestração agentic, onde agentes autônomos trabalham em paralelo no background enquanto o desenvolvedor mantém o foco.

---

## Interfaces Disponíveis

*   **IDE Desktop:** Aplicação desktop principal (fork do VS Code) para macOS, Windows e Linux.
*   **Agents Window:** Painel centralizado dentro da IDE para gerenciar, monitorar e orquestrar múltiplos agentes (incluindo Background Agents e Automations) em uma única interface.

---

## Funcionalidades Principais (2026)

### Assistência em Tempo Real
*   **Cursor Tab:** Autocompletar extremamente avançado que prevê modificações multi-linha e em múltiplos arquivos simultaneamente (ghost text).
*   **Composer 2.5 (Cmd+I / Ctrl+I):** Motor de edição inteligente significativamente melhorado para tarefas longas e complexas, com maior aderência às instruções do usuário e aplicação de diffs visuais em tempo real.
*   **Chat com Contexto (Cmd+L / Ctrl+L):** Chat lateral onde é possível mencionar (`@`) arquivos, pastas, documentações web ou a base de código inteira para consultas contextuais.

### Agentes e Automações
*   **Background Agents:** Permite delegar tarefas complexas e demoradas (refatorações, escrita de testes, implementação de features) para agentes que rodam **na nuvem de forma assíncrona**. O desenvolvedor continua trabalhando normalmente enquanto o agente gera PRs ou propõe alterações para revisão.
*   **BugBot:** Revisor de código automatizado por IA que escaneia Pull Requests no GitHub, identifica bugs lógicos, problemas de segurança e issues de qualidade, e deixa comentários com links "Fix in Cursor" para aplicar correções instantaneamente.
*   **Automations (Multi-Repo & No-Repo):** Automações integradas diretamente na Agents Window, podendo operar em múltiplos repositórios ou independentemente de qualquer repositório (ex: agentes que monitoram Slack, Jira ou métricas de data warehouse).
*   **Integração Jira:** Permite atribuir work items do Jira diretamente a agentes do Cursor, que então corrigem bugs, adicionam features ou atualizam testes com base nos detalhes do ticket.

## Pontos Fortes
*   **Experiência de Usuário (UX):** A integração da IA é nativa e fluida, proporcionando a melhor experiência de pair programming do mercado.
*   **Produtividade Imediata:** Curva de aprendizado zero para quem já usa VS Code.
*   **Paralelismo Real:** A capacidade de rodar múltiplos Background Agents simultaneamente permite escalar a produtividade do desenvolvedor de forma multiplicativa.
*   **Revisão Contínua (BugBot):** A detecção proativa de bugs em PRs reduz significativamente a taxa de defeitos que chegam à branch principal.

---

## Casos de Uso
*   Pair programming contínuo e desenvolvimento diário com autocompletar avançado.
*   Delegação de tarefas de implementação e refatoração para Background Agents.
*   Revisão automática de código em PRs via BugBot antes do merge.
*   Automação de fluxos de trabalho multi-repositório conectados a Jira e Slack.

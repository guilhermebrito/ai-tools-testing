# Cursor

## Visão Geral
Cursor é atualmente a IDE AI-first mais popular do mercado. Construída como um fork do VS Code, ela herda todas as extensões e configurações do ecossistema da Microsoft, mas integra a IA profundamente em cada interação.

## Principais Funcionalidades
- **Cursor Tab:** Um autocompletar extremamente avançado que não apenas sugere a próxima palavra, mas prevê modificações multi-linha e em múltiplos lugares (ghost text).
- **Composer (Cmd+I / Ctrl+I):** Permite pedir à IA para modificar partes do código com um modal pop-up, aplicando diffs visuais em tempo real.
- **Chat com Contexto (Cmd+L / Ctrl+L):** Chat lateral onde você pode facilmente mencionar (`@`) arquivos, pastas, documentações da web, ou até a base de código inteira.

## Pontos Fortes
- **Experiência de Usuário (UX):** A integração da IA é nativa e fluida, diferente de simples extensões instaladas em outras IDEs.
- **Produtividade Imediata:** A curva de aprendizado é zero para quem já usa VS Code.

## Casos de Uso
- Pair programming contínuo e desenvolvimento diário.
- Criação de novas funcionalidades com assistência linha a linha.
- Descoberta e entendimento rápido de código desconhecido através do Chat lateral.

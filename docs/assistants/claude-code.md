# Claude Code

## Visão Geral
Claude Code é o assistente de linha de comando (CLI) oficial desenvolvido pela Anthropic, alimentado pela família de modelos Claude (destaque para o Claude 3.7 Sonnet). 

## Como Funciona
Diferente de editores de código tradicionais, o Claude Code vive diretamente no seu terminal. Ele pode:
- Ler e analisar arquivos e diretórios na sua base de código.
- Sugerir e aplicar modificações diretamente nos arquivos.
- Executar comandos para testar e validar o código (com a permissão do usuário).

## Pontos Fortes
- **Raciocínio Excepcional:** A capacidade do Claude de lidar com raciocínio lógico profundo torna-o excelente para refatorações complexas.
- **Contexto Longo:** Pode absorver grandes partes da sua base de código para tomar decisões assertivas.
- **Foco e Velocidade:** Para desenvolvedores "terminal-first", elimina a necessidade de trocar de janelas.

## Casos de Uso
- Auditoria e refatoração de projetos legados.
- Análise de erros de build diretamente pelo log do terminal.
- Criação rápida de boilerplates e scripts sem sair do ambiente CLI.

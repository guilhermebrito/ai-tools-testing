# BMAD (Breakthrough Method for Agile AI-Driven Development)

## Visão Geral
BMAD não é um software, mas sim uma **metodologia** open-source desenhada para trazer estrutura, disciplina e práticas de engenharia de software profissional para o desenvolvimento assistido por IA.

## Como Funciona
O BMAD combate o "vibe coding" (programar por tentativa e erro com prompts não estruturados) tratando a IA como um time virtual de especialistas.
- **Divisão de Papéis:** Em vez de usar um assistente generalista, você interage com a IA usando personas específicas: Product Manager (PM), Arquiteto, Desenvolvedor, Scrum Master e QA.
- **Arquivos como Fonte da Verdade:** O método exige a criação de artefatos em Markdown (Ex: Product Requirements Document - PRD, Architecture Specs, User Stories). 
- Quando o "Desenvolvedor" (IA) vai codar, ele recebe o contexto estrito desses documentos, evitando alucinações.

## Pontos Fortes
- **Escalabilidade:** Permite que IAs desenvolvam sistemas grandes e complexos sem se perder no contexto.
- **Prevenção de "Spaghetti Code":** Ao forçar o planejamento arquitetural antes do código, a qualidade do software resultante é muito superior.
- **Agnóstico de Ferramenta:** Pode ser usado em conjunto com Claude Code, Cursor, Cline, ou qualquer outra ferramenta que suporte arquivos de contexto.

## Casos de Uso
- Construção de plataformas SaaS do zero.
- Equipes que desejam padronizar o uso de IA entre seus desenvolvedores.
- Refatorações de sistemas onde a regra de negócio não pode ser perdida.

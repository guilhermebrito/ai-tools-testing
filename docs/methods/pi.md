# Pi (earendil-works/pi/coding-agent)

## Visão Geral
Pi é um toolkit open-source voltado para a criação e interação com agentes de inteligência artificial. O módulo `coding-agent` foca em fornecer uma interface de terminal robusta e uma API unificada para modelos de linguagem.

## Como Funciona
- **Interface TUI (Terminal User Interface):** Oferece uma interface gráfica rica direto no terminal para interação com os agentes.
- **API Unificada:** Permite abstrair a complexidade de se conectar com diferentes provedores (OpenAI, Anthropic, Ollama, vLLM).
- **Integração:** Possui suporte para bots no Slack, facilitando o uso do agente de forma colaborativa em um time.

## Pontos Fortes
- **Hackabilidade:** Extremamente customizável para desenvolvedores que querem construir sua própria plataforma de agentes.
- **Foco em CLI:** Traz ferramentas de produtividade para o terminal sem a necessidade de depender de serviços web proprietários.

## Casos de Uso
- Equipes que desejam hospedar seus próprios pods de LLM (vLLM) e integrá-los aos seus fluxos de CI/CD.
- Criação de bots de desenvolvimento internos para Slack/Discord.
